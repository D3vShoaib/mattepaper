# React + TypeScript + Vite + shadcn/ui

This is a template for a new Vite project with React, TypeScript, and shadcn/ui.

## Adding components

To add components to your app, run the following command:

```bash
npx shadcn@latest add button
```

This will place the ui components in the `src/components` directory.

## Using components

To use the components in your app, import them as follows:

```tsx
import { Button } from "@/components/ui/button"
```

## PWA

Mattepaper ships as an installable offline-first PWA.

- The web app manifest is generated by `vite-plugin-pwa` in `vite.config.ts`
  (name, colors, icons, shortcuts, launch behavior, and standalone display).
- App icons live in `public/icons/`. The SVG sources are
  `favicon.svg` (the tab icon, which follows the browser theme), `icon.svg`,
  `icon-square.svg`, and `icon-monochrome.svg`; the PNG sizes, the Apple
  touch icon, and the maskable icons are rendered from the same Books02 glyph.
- The in-app launch splash is in `index.html`, with its theme initialized
  before first paint by `public/app-init.js`.
- Install and update UI lives in `src/features/pwa/`. Install buttons only
  appear when the browser offers installation, and updates show a reload
  prompt instead of swapping the app out from under the reader.
- Workbox precaches the app shell (including the icons)
  while imported EPUBs stay in IndexedDB.

Service workers and installation need a production build (or another secure
origin). To test locally:

```bash
pnpm build
pnpm preview
```
